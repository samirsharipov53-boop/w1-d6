
### Task1    
Write a Method **`int FindMid(int a, int b, int c)`**  that finds the average of three given numbers.    

----

Напишите функцию **`int FindMid(int a, int b, int c)`**, которая находит среднее из трех заданных чисел.

----

Функсияи **`int FindMid(int a, int b, int c)`** нависед, ки аз се адади додашуда рақами миёнашонро меёбад.      

Адади миёна гуфта рақами байни калонтарин ва хурдтаринро дар назар доранд.

**Input**
```
7 4 5
```
**Output**
```

```

### Task2 
Write C# program that takes two integers as an input. If they have the same sign print "`True`", otherwise print "`False`";

----

Напишите программу на C#, которая принимает на вход два целых числа. Если они имеют одинаковый знак, выведите "`True`", иначе выведите "`False`";

----

Барномаи C#-ро нависед, ки ду ададро ҳамчун вуруд қабул мекунад. Агар онҳо аломати якхела дошта бошанд,   
"`True`"" чоп кунед , дар акси ҳол "`False`" чоп кунед. 

Aломати якхела яъне агар ҳардуш позитив(мусбӣ) ва ё ҳардуш негатив(манфӣ) бошад, "`True`", набошад "`False`"

`Позитив(мусбӣ)`===> рақамҳое ки аз 0 калонанд.

`Негатив(манфӣ)`===> рақамҳое ки аз 0 хурдaнд.

**Input**
```
7 10
```
**Output**
```
True
```
